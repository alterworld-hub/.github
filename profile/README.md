# alterworld-hub

Event platform deployed as a tree of autonomous nodes. Each node runs the same software on k3s; data flows up the tree, configuration is pulled from git.

- Conventions: [.github/CONVENTIONS.md](https://github.com/alterworld-hub/.github/blob/main/CONVENTIONS.md)
- Node state: [gitops](https://github.com/alterworld-hub/gitops)
